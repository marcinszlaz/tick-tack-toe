## Usefull commands git / gh
* `gh repo create https://github.com/marcinszlaz/tick-tack-toe.git --public` - create repo on github,

* `git push --set-upstream origin main` - set upstream and push data to repo,

## Usefull commands Emacs
* C - control key, W - alt key, 
* `Ctrl-w` - cut, `Alt-w` - copy, `Ctrl-y` - paste, `Ctrl-Space` - mark text,
* `C-x-s` - save your work, `C-x-f` - open file, `C-x-c` - quit
* `C-c . ` - insert date from calendar (`shift -> <-` change date)
* `C-c-t` if you have list make TODO, mulitple times = TODO/DONE/oridnary text
* `C-c-d` - insert deadline date xD,
